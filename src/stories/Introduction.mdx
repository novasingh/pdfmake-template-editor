# 📄 pdfmake-editor

A powerful, drag-and-drop PDF template editor for React that generates `pdfmake` JSON definitions. Build complex document layouts visually and export them as high-quality PDFs instantly.

## 🚀 Key Features

- **Intuitive Drag & Drop**: Built with a custom zero-dependency drag-and-drop engine (Pointer Events API) for a smooth, native-feeling layout experience.
- **Rich Component Library**: Headings, Paragraphs, Images, Tables, Columns, and specialized Business Modules.
- **Real-time Preview**: Synchronized canvas and PDF export capabilities.
- **Theming & Localization**: Fully customizable UI to match your brand's look and feel.

## 🌍 Multi-language Support

The editor comes with built-in translations for:
- 🇺🇸 English (`en`)
- 🇨🇳 Chinese (`zh`)
- 🇪🇸 Spanish (`es`)
- 🇩🇪 German (`de`)
- 🇷🇺 Russian (`ru`)
- 🇯🇵 Japanese (`ja`)
- 🇫🇷 French (`fr`)

You can also provide a custom `labels` object in the `config` to override any text or add a new language.

### 🛠️ Components
Deep dives into the individual building blocks:
- **EditorHeader**: Control bar for saving, exporting, and settings.
- **Sidebar**: The component gallery and page property controls.
- **PropertiesPanel**: Context-aware styling controls for selected elements.

## 📖 Quick Start

```tsx
import { TemplateEditor } from 'pdfmake-editor';
import 'pdfmake-editor/dist/index.css';

const MyEditor = () => (
  <div style={{ height: '100vh' }}>
    <TemplateEditor 
      onSave={(doc) => console.log('Saved:', doc)}
    />
  </div>
);
```
